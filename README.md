# 建造者世界 Builder World ($建造世界)

单文件网站：`index.html`，没有文件夹，无需构建，可直接部署到 Vercel / GitHub Pages。

## 上线前修改
在 `index.html` 脚本顶部的 `CONFIG` 中填写：
- `xUrl`：官方 X
- `ca`：$建造世界 的 BEP-20 合约地址
- `buyUrl`：购买链接（例如 PancakeSwap）

## 说明
- 全站中文，面向 BNB Chain：BNB 计价、BEP-20、MetaMask / Trust / OKX 钱包（只读连接，提示切换到链 ID 56）。
- 材料、代币、派发、奖池和实时动态均为示例，并在页面上标明；发射为预览，上线后开放。
- 页脚声明本项目与 Binance（币安）、BNB Chain 官方、PancakeSwap 无关，请保留。
